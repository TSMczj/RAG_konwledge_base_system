0使用说明

编号规则：T-<阶段>.<序号>，例如 T-1.3。

标记含义
S单文件、逻辑简单，一气呵成
M需要设计取舍，可能要调几次才对
L涉及多模块配合或需要实测调优

单条任务的完成定义（DoD）：① 代码能跑通；② 交付物落到指定路径；③ 满足该条验收口径；④ 涉及的可调参数已进 .env，没有硬编码。

10开发约定

项约定
提交粒度一个任务一次提交，message 带编号，如 feat(T-1.3): PDF 按页解析
分支策略单人开发可直接用 main；想稳一点用 dev 分支，阶段验收通过再合
命名文件 / 函数 snake_case；类 PascalCase；常量大写
配置任何可调值都不许硬编码，一律进 .env / config.py
日志关键路径打点：解析耗时、检索耗时、token 用量
测试涉及外部 API 的一律 mock，测试不花钱
